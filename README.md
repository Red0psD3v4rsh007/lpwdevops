# Cloud Native Applications & DevOps Lab (`lpwdevops`)

Repository containing practical assignments, laboratory reports, Kubernetes manifests, CI/CD pipelines, and project code for the Cloud Native Applications and DevOps course.

---

| Practical / Directory | Description | Key Components |
|---|---|---|
| **PR1** | Practical 1 Documentation & Report | Lab Report (`.pdf`, `.docx`) |
| **PR2** | Practical 2 Documentation & Report | Lab Report (`.pdf`, `.docx`) |
| **PR3** | AWS ECS, ECR & Lambda Deployment | Flask App, Dockerfile, ECS Task Definitions, Deployment Scripts |
| **PR4** | Practical 4 Documentation & Report | Lab Report (`.docx`) |

| **PR10** | DevSecOps CI/CD Automation | CI/CD Pipeline, Ingress, Deployment Manifests |
| **minikube** | Minikube Cluster Screenshots & Setup | Verification captures |

## 🛠 Prerequisites & Tools
- **Docker** & **Docker Compose**
- **Kubernetes** (`kubectl`, **Minikube**)
- **AWS CLI** (for ECS / ECR / Lambda deployments)
- **Trivy** & **Bandit** (DevSecOps scanning)
- **Python 3.x** / **Node.js**
